Repères chronologiques incontournables

  • 622 : l'Hégire ; 800 : couronnement de Charlemagne ; 1054 : schisme entre chrétiens d'Orient et d'Occident ; 1096-1099 : première croisade ; 1258 : prise de Bagdad par les Mongols.
  • 1492 : premier voyage de Christophe Colomb ; 1517 : début de la Réforme (Luther) ; 1598 : édit de Nantes ; 1661-1715 : règne personnel de Louis XIV ; 1685 : Code noir et révocation de l'édit de Nantes.
  • 1789 : début de la Révolution française, Déclaration des droits de l'homme et du citoyen ; 1792 : proclamation de la République ; 1804 : Napoléon Ier empereur ; 1848 : suffrage universel masculin et abolition de l'esclavage ; 1870 : début de la IIIe République ; 1881-1882 : lois Ferry ; 1905 : loi de séparation des Églises et de l'État.
  • 1914-1918 : Première Guerre mondiale ; 1917 : révolutions russes ; 1936 : Front populaire ; 1939-1945 : Seconde Guerre mondiale ; 18 juin 1940 : appel du général de Gaulle ; 1944 : droit de vote des femmes ; 1945 : fin de la guerre, création de l'ONU.
  • 1947-1991 : guerre froide ; 1957 : traités de Rome ; 1958 : Ve République ; 1962 : indépendance de l'Algérie ; 1989 : chute du mur de Berlin ; 1992 : traité de Maastricht ; 2002 : l'euro en circulation.

Les compétences évaluées

  • Se repérer dans le temps : situer un fait sur une frise, ordonner, identifier des continuités et des ruptures, périodiser.
  • Se repérer dans l'espace : localiser les continents, océans, grands ensembles, États et grandes métropoles ; nommer et localiser les régions et grandes villes françaises, les territoires ultramarins, les États de l'Union européenne.
  • Analyser des documents : identifier la nature, l'auteur, la date, le contexte ; extraire et confronter des informations ; exercer un regard critique.
  • Pratiquer différents langages : réaliser ou compléter une carte, un croquis, un schéma, une frise chronologique ; rédiger une réponse argumentée.
  • Raisonner : expliquer un phénomène, changer d'échelle, justifier une démarche.
